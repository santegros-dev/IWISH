# IWISH

- Общение с владельцем (Ilia) на русском; тексты интерфейса на русском.
- План продукта и принятые решения: docs/plan.md.
- Бизнес-логика живёт в src/lib и принимает `db` параметром, чтобы тестироваться на реальной базе (tests/). Страницы и Server Actions только проверяют ввод и вызывают её.
- Каждый Server Action сам проверяет права (requireUser / владелец списка / гость брони).
- Автор никогда не должен видеть, кто забронировал подарок; гости видят только «свободно / занят / вы дарите».
- Ссылки на магазины всегда через outbound_links и /go/<id>.
- После изменения src/db/schema.ts: `npm run db:generate`.
